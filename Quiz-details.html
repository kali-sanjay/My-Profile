Quiz Web Application

Quiz Web Application

Quiz is an interactive web application developed using HTML, CSS and JavaScript. The application allows users to answer Java-related questions and calculate their final score.

The project focuses on creating an interactive user experience using JavaScript for question navigation and score calculation.

Key Features

  • Displays Java-related questions
  • Displays questions one by one
  • Next button navigation
  • User answer selection
  • Automatic score calculation
  • Interactive user interface

Technologies Used

Frontend: HTML, CSS, JavaScript

JavaScript: Question navigation and score calculation

Project Highlights

This project helped me understand JavaScript event handling, DOM manipulation, user input handling and dynamic score calculation.

I also learned how to create an interactive web application where the page content changes according to the user's actions.
