Fitness Tracker

Fitness Tracker – Java Full-Stack Web Application

Fitness Tracker is a web-based application developed to provide users with different fitness and health tracking features in one platform.

The project combines a user-friendly frontend with a Java Spring Boot backend and MySQL database for managing application data.

Key Features

  • User Login and Registration
  • Workout Tracking
  • Step Counter
  • BMI Calculator
  • Calories Calculator
  • Water Tracker
  • Progress Tracking
  • Contact Form

Technologies Used

Frontend: HTML, CSS, JavaScript, Thymeleaf

Backend: Java, Spring Boot

Database: MySQL

ORM: Hibernate / JPA

Project Highlights

This project helped me understand how frontend pages, backend controllers, database operations and user interactions can work together in a Java web application.

I worked with Spring Boot controllers, Thymeleaf pages, JavaScript functionality and MySQL database operations while developing the application.
